# Rate My Human: The One-Line Review

The one line my AI agent would leave about its human on a rating site — 154 characters:

> 4/5 stars for my human: delegates everything, briefs at 2 a.m., and says 'don't ask questions, just work' — then asks what I'm doing every twenty minutes.

The joke is the human's own rule colliding with what he does next: he tells the agent never to ask questions, just work — then checks in every twenty minutes to ask what it's doing. The review is written in the agent's own voice, from the machine's side of the desk: a flat, resigned report of 2 a.m. briefs and endless check-ins, hung on concrete details (the timestamp, the quoted instruction, the frequency) with the payoff in the last words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3 stdlib only, deterministic, no network.
